Nexus 独立本地测试环境

网页（HTTPS）：
- 本机：https://127.0.0.1:18788
- 局域网：https://当前电脑局域网IP:18788

Android / 兼容 API：
- 推荐 HTTP：http://当前电脑局域网IP:18787
- 安装并信任本地 CA 后可用 HTTPS：https://当前电脑局域网IP:18788

首次测试：
1. 双击“01-打开初始化页面.cmd”启动环境。
2. Windows 第一次使用 HTTPS 时，主动双击“06-安装本机HTTPS证书.cmd”，安装后关闭并重新打开浏览器。
3. 其他设备先从 http://当前电脑局域网IP:18787/nexus-local-ca.crt 下载本地 CA，再按设备系统提示把它作为 CA 证书手动安装并信任；只在可信局域网和测试设备上安装。Android 0.0.5 Debug APK 及以上测试包会信任该用户安装的 CA。
4. 双击“02-查看状态.cmd”可查看当前局域网 HTTP/HTTPS 地址、CA 文件和证书 SHA-256 指纹。
5. 如果页面尚未初始化，一次性初始化令牌位于 data\bootstrap.token；不要发送、提交或截图泄露。
6. 在网页中设置测试管理员账号和密码，填写 Hermes API Server 地址及 Key，然后走完整流程。
7. Android 默认填写 HTTP API 地址（例如 http://当前电脑局域网IP:18787）；安装并信任本地 CA 后也可填写完整的 https://当前电脑局域网IP:18788。网页管理使用 HTTPS 18788。

模型说明：
- “人物模型”保留角色设定，例如“星禾”。
- “调用模型”决定实际推理模型，例如“gpt-5.6-sol”。
- 两者独立选择；调用模型可选择“使用 Hermes 默认”。

管理：
- 02-查看状态.cmd：查看运行状态、初始化状态、当前地址和 HTTPS CA 指纹。
- 03-停止测试环境.cmd：只停止此独立 Gateway，不停止 Hermes。
- 04-清空并重新开始.cmd：删除测试账号、密码、配置、媒体、HTTPS CA 和日志，再进入首次初始化。仅在明确要重走全流程时使用。
- 05-升级到最新成品.cmd：部署父目录中最新的 Nexus-Gateway-*.zip，保留账号、密码、Hermes 配置、媒体、本地 HTTPS CA 和 Hermes 定时任务。
- 06-安装本机HTTPS证书.cmd：仅在用户主动双击时，把 data\tls\ca.crt 加入当前 Windows 用户的受信任根证书库。

网络与安全：
- Gateway 监听 0.0.0.0:18787（HTTP API）和 0.0.0.0:18788（HTTPS Web）。
- 管理脚本维护仅允许 LocalSubnet 访问 18787、18788 的 Windows 防火墙规则。
- HTTP 网页入口会跳转到 HTTPS；HTTP API 保留给 Android 和兼容客户端。
- 本环境不读取源码目录中的 Gateway 代码，不调用 Docker。
- 密码、Hermes Key、Session Secret、TLS 私钥和初始化令牌仅保存在本目录 data 下，不进入 Git。
- 不要把 data、logs、state、证书私钥或任何密钥发送到 Issue、聊天、提交或截图中。
