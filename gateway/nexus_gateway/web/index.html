反向代理说明

Nexus Gateway 提供 HTTP 源站，不会强制跳转 HTTPS，也不要求 App 安装证书。

局域网可直接访问；外网部署建议由 Nginx、Caddy 或其他反向代理提供 HTTPS 域名，并转发到当前 HTTP 端口。

建议转发http://127.0.0.1:8787
