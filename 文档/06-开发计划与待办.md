# Nexus 开发计划与待办

更新原则：优先稳定现有能力，新功能后置；每项必须有可判断的完成标准。

## P0｜本轮必须完成

- [x] Token 仅发送到同源 Nexus 网关
  - 完成标准：跨域图片和下载请求不含 Authorization，同源请求仍可认证。
- [x] 首次初始化防抢占与配置损坏 fail closed
  - 完成标准：初始化需要一次性凭据；已有配置损坏时 setup 不可用。
- [x] 管理员密码哈希存储和旧格式迁移
  - 完成标准：账号文件不再保存明文密码，旧文件首次加载后可登录并迁移。
- [x] 登录限速
  - 完成标准：连续失败触发 429/退避，成功登录后恢复正常。
- [x] 多会话本机后台监控
  - 完成标准：启动第二个会话监控不会取消第一个会话。
- [x] 登出仅取消本机任务
  - 完成标准：本机流、上传、下载、监控和通知清理；不调用 Hermes/Gateway stop。
- [x] 缓存键和通知标识碰撞修复
  - 完成标准：不同会话和文件得到稳定且独立的键、通知 ID、PendingIntent。
- [x] 持久 URI 权限
  - 完成标准：OpenDocument 文件重启后仍可读取；失败路径有明确处理。
- [x] SSE 标准 JSON 解析
  - 完成标准：Unicode、Emoji、反斜杠和多行 data 测试通过。

## P1｜同版本安全加固

- [x] HTTP 明文连接显著提示，但保留局域网自用能力。
- [x] 锁屏回答通知默认隐藏会话敏感标题/内容。
- [x] 网关上传总配额、数量或磁盘低水位保护。
- [x] 服务器绝对路径和原始异常不进入客户端/API 响应。
- [x] Gradle Wrapper 校验和及不破坏构建的供应链固定。
