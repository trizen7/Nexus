# Nexus 版本更新记录

本项目遵循 `0.0.x` 小步版本规则。本记录只写入已经实现并完成验证的内容；尚未完成的工作保留为“进行中”或“待验证”。

## 0.0.8｜移动端设置、输入体验与 Web 管理页重构

状态：功能实现、完整自动验证、成品构建、独立测试环境升级和移动 Web 验收均已完成，待用户真机与正式反向代理验收。

已完成：

- Android 新增独立全屏设置页，集中管理人物模型、实际调用模型、推理深度、定时任务、自动刷新、主题、连接信息和退出登录；模型及定时任务子页关闭后返回设置页；
- Android 使用 Material 3 重新设计登录、聊天、会话抽屉、输入区和设置界面，统一蓝紫/青绿色视觉、卡片层级、圆角和暗色主题；
- 登录页支持滚动及状态栏、导航栏和 IME 安全区，启用 `adjustResize`，软键盘不再遮挡密码栏；密码支持显隐并实时显示已输入位数；
- 聊天输入状态与整页 UI 状态解耦，草稿磁盘保存改为 350ms 防抖，并在切换会话、发送和 App 进入后台前强制落盘，减少输入法弹出和连续打字时的主线程工作；
- 人物模型与实际调用模型继续独立保留，新增可持久化的推理深度选择；手机端继续支持定时任务的新建、编辑、暂停、恢复、立即运行和删除，普通对话列表不显示定时任务执行会话；
- Android 接受显式 HTTP 或 HTTPS，裸地址默认补全 HTTP；不再强制公网 HTTPS，也不再显示证书安装提示。HTTPS 仍使用 Android 系统信任链，正式公网部署建议由反向代理提供受信任证书；同源 Bearer Token 防泄漏校验继续保留；
- Web 端改为专用初始化与运维管理页，移除聊天、会话和消息输入界面，保留概览、文件、语音、账号安全和系统状态；移动导航采用受约束的横向滚动，不再把整页撑宽；Android 使用的聊天 API 保持不变；
- 建立 Hermes 原版只读强制边界：Nexus 禁止修改任何 Hermes 文件，禁止安装、升级、降级、卸载、启动、停止、重启或终止 Hermes，只能通过原版 Hermes HTTP API 工作；测试、清理、升级和部署仅允许写入 Nexus 自有目录；
- 历史上曾在本机将 Hermes 更新至 `0.19.0` 并配置 `gpt-5.6-sol` 路由；该事实仅作记录，自 0.0.8 起禁止复现，也禁止通过再次修改 Hermes 来“恢复原状”；
- 独立成品测试环境继续位于 `成品\本地测试环境\`，只运行构建后的 Gateway ZIP，不读取源码、不运行 Docker；普通升级保留账号、Nexus 保存的 Hermes 上游连接配置副本、媒体、日志、状态和历史 `data\tls`。

## 0.0.7｜HTTP 源站与 HTTPS 反向代理

状态：功能实现、自动验证、成品构建和独立测试环境升级均已完成，待用户真机及正式反向代理验收。

已完成：

- Gateway 改为单一 HTTP listener，删除自动证书、临时 CA、正式证书热更新、TLS 环境变量及 `--tls-dir`；网页删除证书管理入口，并明确 HTTP 源站与反向代理职责；
- 旧 `/api/admin/tls` 路径显式停止服务，避免被通配代理转发给 Hermes；Gateway 不依据外部传入的 `X-Forwarded-*` 改写安全判断；
- Nginx/Caddy 部署文档补充 HTTPS 终止、`Host` 与 `X-Forwarded-Proto` 转发、流式响应关闭缓冲、长读取超时、HSTS 及源站端口隔离；
- Android 允许回环、私网、链路本地、CGNAT、IPv6 ULA 和 `.local` 地址使用 HTTP，同时拒绝公网 HTTP；
- 裸私网地址默认规范化为 `http://地址:18787`，裸公网域名默认规范化为 `https://域名`；旧私网 `https://地址:18788` 自动迁移回 `http://地址:18787`；
- Android 移除 Debug CA 生成、内嵌和安装流程；HTTPS 反向代理仅使用 Android 系统信任链；Bearer Token 只附加到通过校验且与 Gateway 同源的资源请求；
- 人物模型、实际调用模型、推理深度与手机端定时任务管理均保留，普通对话列表继续隐藏 `source=cron` 会话；

- 独立环境 upgrade 只替换 `app/` 并同步运行依赖，保留账号、Hermes 配置、媒体、运行数据和历史 `data/tls`；旧 HTTPS `18788` 必须关闭；
- Windows 防火墙只保留 LocalSubnet TCP `18787` 入站规则，公网入口由后续反向代理单独管理。

## 0.0.6｜推理深度、HTTPS-only 与证书热更新

状态：功能实现、自动验证、成品构建和独立测试环境升级均已完成，待用户真机验收。
