# Nexus 版本更新记录

本项目遵循 `0.0.x` 小步版本规则。本记录只写入已经实现并完成验证的内容；尚未完成的工作保留为“进行中”或“待验证”。

## 0.0.2｜安全与多会话稳定性加固

状态：开发中

计划范围：

- 阻止 Nexus 设备令牌发送到第三方 URL，仅对同源网关请求附加认证；
- 首次初始化增加防抢占保护，配置损坏时关闭初始化入口；
- 网关管理员密码改为加盐哈希存储，并兼容旧账号文件迁移；
- 登录接口增加轻量限速；
- 多个会话可同时进行本机后台状态监控；
- 登出时只取消 App 本机流、上传、下载和监控，不停止 Hermes 服务端任务；
- 修复会话缓存键、通知 ID 与 PendingIntent 碰撞；
- 文件草稿取得可持久 URI 读取权限；
- SSE 内容改用标准 JSON 解析；
- 增加 HTTP 风险提示、锁屏隐私、上传配额和供应链基础加固。

验证结果：待本轮实现完成后补录。

## 0.0.1｜首个 Nexus 开源版本

- 完成 Nexus 品牌、包名 `app.nexus.mobile` 与 `nexus_gateway` 网关统一；
- 提供 Android 多会话、附件、下载、通知、草稿和长会话分页；
- 提供账号认证、Hermes 会话代理、SSE、媒体和 Web 管理；
- 提供 Docker、NAS 部署、CI、许可证、安全与贡献文档；
- 星禾移动端 v0.0.20 冻结为历史最终版，后续开发统一进入 Nexus。
