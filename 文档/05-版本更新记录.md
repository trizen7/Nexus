# Nexus 版本更新记录

本项目遵循 `0.0.x` 小步版本规则。本记录只写入已经实现并完成验证的内容；尚未完成的工作保留为“进行中”或“待验证”。

## 0.0.6｜推理深度、HTTPS-only 与证书热更新

状态：功能实现、自动验证、成品构建和独立测试环境升级均已完成，待用户真机验收。

已完成：

- Android 保留“人物模型”，继续独立选择实际调用模型，并新增推理深度选择、当前值展示与持久化；
- 推理深度支持默认、`none`、`minimal`、`low`、`medium`、`high`、`xhigh`、`max`、`ultra`；默认不发送字段，其余值通过 `reasoning_effort` 发送；
- Gateway 校验并透传 `reasoning_effort`。Nexus 只负责 UI、持久化、校验和透传，不声明 Hermes 或调用模型一定实际采用；
- Android 与网页普通对话列表均过滤 `source=cron` 的定时任务执行会话；手机端继续通过专用界面新建、编辑、暂停、恢复、立即运行和删除定时任务；
- Gateway 改为单一 HTTPS listener，HTTP 完全禁用，TLS 最低 1.2；
- Gateway 首次启动自动生成并持久化临时 CA/服务器证书，局域网 IP 或 SAN 变化时只重签服务器证书；现在无需提供正式证书；
- 网页“系统状态”新增证书状态和正式 PEM 证书链/未加密私钥上传，支持校验、原子替换、备份、热加载与失败回滚；正式证书可在以后取得后再配置；
- Android 禁止明文 HTTP，裸地址默认使用 HTTPS，裸局域网 IP 未写端口时补 `18788`；旧保存的本地 `http://IP:18787` 自动迁移为 `https://IP:18788`；
- Debug 构建支持通过 `NEXUS_DEBUG_CA_FILE` 内嵌成品测试环境 CA，并拒绝包含私钥的输入；Release 仍只信任系统 CA；
- 独立成品测试环境只运行 Gateway ZIP、不读取源码、不运行 Docker，只允许 LocalSubnet 访问 TCP 18788；upgrade 保留账号、Hermes 配置、媒体和整个 `data/tls`，reset 才删除 CA；
- Docker、Compose、环境变量示例和源码本地测试脚本同步为 HTTPS-only；按要求不在本机运行 Docker 测试。

- Android：126 项 Debug JVM 单元测试全部通过，`lintDebug` 通过，`assembleDebug` 构建成功；
- 成品：生成 `Nexus-Android-0.0.6-debug.apk` 与 `Nexus-Gateway-0.0.6.zip`；APK 内嵌 CA 与独立测试环境当前 CA 完全一致且不同于源码占位 CA；Gateway ZIP 文件清单完整，不含运行数据、缓存或私钥；

## 0.0.2｜安全与多会话稳定性加固

状态：源码修复和自动验证已完成，待真机验收。

已完成：

- Nexus 设备令牌仅附加到与当前网关同源的图片和下载请求，第三方 URL 不再携带认证；
- HTTP 登录增加明文风险确认，保留可信局域网 HTTP 自用能力；
- 首次初始化改为一次性 Bootstrap Token，成功后自动删除；配置或账号文件损坏时 fail closed；
- 网关管理员密码改为 scrypt 加盐哈希，旧明文账号在成功登录后自动迁移；
- 登录按来源 IP 限速；
- 多个会话可同时进行本机后台状态监控；
- 登出只取消 App 本机流、上传、下载、监控和通知，不停止 Hermes 服务端任务；
- 会话缓存键改为稳定编码，通知 ID 与 PendingIntent 按类型、会话和文件隔离；
- OpenDocument 文件取得持久读取权限，不支持时复制到 App 私有缓存；
- SSE 使用 Gson 标准 JSON 解析，支持 Unicode、Emoji、反斜杠和多行 data；
- 回答和文件通知默认使用锁屏隐私模式；
- 网关增加上传总配额、磁盘低水位、绝对路径隐藏和错误脱敏；
- Gradle Wrapper 增加官方 SHA-256 校验。
