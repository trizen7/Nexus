# Nexus 版本更新记录

本项目遵循 `0.0.x` 小步版本规则。本记录只写入已经实现并完成验证的内容；尚未完成的工作保留为“进行中”或“待验证”。

## 0.0.3｜移动模型选择与定时任务管理

状态：功能实现和自动验证已完成，待用户真机验收。

已完成：

- 普通对话列表过滤 `cron` 渠道，定时任务执行记录不再作为对话显示；
- 登录后非阻塞加载 Hermes 模型列表，可从聊天页菜单和设置页选择模型；
- 模型选择持久保存，发送消息时携带选定模型；
- Gateway 在指定模型时转发至 Hermes `/v1/chat/completions`，并把 OpenAI SSE 转换为移动端现有事件协议；
- 未指定模型时继续使用 Hermes 原生 Session Chat 路由；
- 手机端新增全屏定时任务管理页；
- 支持任务列表、刷新、新建、编辑、删除、暂停、恢复和立即运行；
- 表单支持 Cron、`every 2h` 固定间隔和 ISO 单次时间；
- 表单输入校验和服务器错误直接显示在编辑/删除弹窗内。

自动验证：

- Gateway：65 项测试通过，9 项按环境条件跳过；
- Android：115 项 JVM 单元测试通过，0 failures / 0 errors / 0 skipped；
- Android Lint：无 Error；
- Debug APK：构建成功。

待真机确认：模型切换后的实际回答、窄屏任务管理布局、任务 CRUD 和暂停/恢复/立即运行操作。

## 0.0.2｜安全与多会话稳定性加固

状态：源码修复和自动验证已完成，待真机验收。

已完成：

- Nexus 设备令牌仅附加到与当前网关同源的图片和下载请求，第三方 URL 不再携带认证；
- HTTP 登录增加明文风险确认，保留可信局域网 HTTP 自用能力；
- 首次初始化改为一次性 Bootstrap Token，成功后自动删除；配置或账号文件损坏时 fail closed；
- 网关管理员密码改为 scrypt 加盐哈希，旧明文账号在成功登录后自动迁移；
- 登录按来源 IP 限速；
- 多个会话可同时进行本机后台状态监控；
- 登出只取消 App 本机流、上传、下载、监控和通知，不停止 Hermes 服务端任务；
- 会话缓存键改为稳定编码，通知 ID 与 PendingIntent 按类型、会话和文件隔离；
- OpenDocument 文件取得持久读取权限，不支持时复制到 App 私有缓存；
- SSE 使用 Gson 标准 JSON 解析，支持 Unicode、Emoji、反斜杠和多行 data；
- 回答和文件通知默认使用锁屏隐私模式；
- 网关增加上传总配额、磁盘低水位、绝对路径隐藏和错误脱敏；
- Gradle Wrapper 增加官方 SHA-256 校验。

自动验证：

- Gateway：41 项测试通过，Python 编译检查通过；
- 网页契约：通过；
- Android 临时 ASCII 副本：99 项 JVM 测试通过，0 failures / 0 errors / 0 skipped；
- Android Lint：无 Error；
- Debug APK：构建成功，生成约 17.6 MB 安装包；
- GitHub CI：待推送后确认。

待真机确认：HTTP 风险弹窗、多会话后台通知、登出后的服务器任务续跑、附件重启恢复和外部 URL 下载行为。

## 0.0.1｜首个 Nexus 开源版本

- 星禾移动端 v0.0.20 冻结为历史最终版，后续开发统一进入 Nexus。
